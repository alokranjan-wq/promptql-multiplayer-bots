# Website Redesign: typesafe.ai

Link to create new bot: https://ql.app/l/8AdNzXjb

Redesigns www.typesafe.ai to match how good the product is. The bot keeps the site's voice and copy word for word, plans a new visual direction, and then builds it with micro-animations, interactivity, and strong visual hierarchy. It hands over a live preview, before and after screenshots, and a summary of its design choices.

Set the bot's model to Opus 5.5 before you send the prompt.
